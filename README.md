## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally (Development)
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

### Vercel Deployment
The project is pre-configured with `vercel.json` and is ready for 1-click deployment on Vercel.
